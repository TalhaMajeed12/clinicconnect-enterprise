# Project Roadmap

## Completed for v3.0

- Stable Flask application factory and PostgreSQL startup
- Route/template integrity and role-specific authentication
- Admin, clinician, and patient portal workflows
- Clinician management without destructive history deletion
- Appointment conflict, availability, and time-off enforcement
- Visits, prescriptions, patient history, and demo payments
- Audit/API/security/CSRF improvements
- Render production deployment, PostgreSQL backup, and Brevo email
- Focused automated tests, UI cleanup, code cleanup, and documentation

## Submission stage

- Execute and sign the [UAT checklist](UAT_Checklist.md).
- Capture anonymized screenshots for the report and presentation.
- Tag the accepted Git commit after supervisor approval.
- Retain the verified database backup separately from the repository.

## Post-FYP options

- Managed Redis and horizontal scaling
- Indexed privacy-preserving identifier lookup
- Real payment gateway and webhook verification
- Multi-branch and additional staff roles
- Laboratory, document, SMS, and reminder integrations
